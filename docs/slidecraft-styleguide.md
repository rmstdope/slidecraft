# Slidecraft style guide

The look of Slidecraft's own interface: the home page, editor, gallery, chat and presenter
window. Slides follow their deck's theme instead; this guide is for the tool around them.

## Brand

Slidecraft is about structure: a deck is built from parts that fit together. The voice is quiet
and precise, never shouting. Tagline: *structure for your stories*.

## Logo

Two L-shaped brackets at opposite corners, yellow top left and teal bottom right, framing a dot:
the slide frame around the idea at its centre.

- Works on dark and light backgrounds (`public/logo-on-dark.svg`, `public/logo-on-light.svg`;
  the dot is white or ink).
- Clear space around the mark equals the dot's diameter.
- Never smaller than 16 px; never stretched, rotated or recoloured.
- Favicons: `public/favicon.svg` plus PNGs at 16, 32, 48, 64, 128, 180 (Apple touch), 192 and 512 px,
  generated by `node scripts/generate-favicons.mjs`.

## Colour roles

| Token | Value | Role |
|---|---|---|
| `--brand-yellow` | `#f5b400` | the primary accent: headings, primary buttons, active states |
| `--brand-red` | `#e0452b` | errors, destructive actions, alerts |
| `--accent-teal` | `#1f9e89` | AI elements, success, live status |
| `--accent-navy` | `#1f3a5f` / `#7fa7d9` on dark | depth, code blocks on light; links on dark |
| `--accent-gray` | `#8a8f98` | neutral markers |
| `--dark-bg` / `--dark-text` | `#111111` / `#ffffff` | the default interface |
| `--dark-muted` | 60 % white | secondary text |
| `--light-bg` / `--light-text` | `#ffffff` / `#1a1a1a` | light surfaces |

The interface is dark by default: a near-black background keeps attention on the slides.

## Typography

| Use | Face | Size |
|---|---|---|
| H1, wordmark | Zilla Slab, demi-bold, in the primary accent | 3 rem |
| H2 | Zilla Slab | 2 rem |
| H3 | Source Sans 3, bold | 1.5 rem |
| Body | Source Sans 3, 400 | 1 rem |
| Caption | Source Sans 3, muted | 0.875 rem |
| Small | Source Sans 3, muted | 0.75 rem |
| Code | `ui-monospace`, JetBrains Mono, Menlo | 0.875 rem |

Tokens: `--font-display`, `--font-body`, `--font-mono`.

## Spacing and motion

| Token | Value |
|---|---|
| `--space-xs` … `--space-xl` | 0.5, 1, 2, 4, 6 rem |
| `--transition-fast` | 150 ms ease (hover, focus) |
| `--transition-normal` | 300 ms ease (panels, menus) |
| `--transition-slow` | 500 ms ease (page-level changes) |

## Patterns

- **Borders:** 1 px at low opacity (`rgba(255, 255, 255, 0.12–0.15)` on dark) for a quiet grid.
- **Shadows:** light or medium only; never heavy drop shadows.
- **Toolbars and palettes:** dark, slightly transparent panels; the editor's toolbars match the
  command palette.
- **Hover and selection:** panel separators highlight in the primary accent on hover; the active
  tool or selected slide gets a primary-accent border.
- **Imagery:** gradient overlays over hero images; a soft radial accent glow behind the hero.
- **Status:** teal for success and live connections, red for errors, with text, never colour alone.

## Do and don't

| Do | Don't |
|---|---|
| use yellow as the primary accent | introduce colours outside the palette |
| keep to the spacing scale | invent one-off margins |
| use thin, low-contrast borders | use heavy drop shadows |
| keep the interface dark by default | override the type stack |
| put gradient overlays on imagery | distort the logo or shrink it below 16 px |

All values are CSS custom properties in `src/styles/global.css`; use them rather than literals.
